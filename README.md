# Podcast Claim Evolution Atlas

Local Rust/WASM claim histories and evidence-first disagreement review for Castflow.

Source: [project-ideas #11](https://github.com/jpequegn/project-ideas/issues/11).

Implementation tasks #1 through #8 cover contracts, read-only imports, deterministic relations, reviewed history, CLI reports, evaluations, WASM explorer, and final verification.

Real corpus exports stay local. Synthetic examples are not attributed to real speakers. No extractor output is automatically treated as reviewed truth.
